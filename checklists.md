# ✅ Чек-листы для каждого урока

Эти чек-листы помогут вам не пропустить ни одного шага. Отмечайте пункты по мере выполнения.

---

## Урок 1 — Первая страница

- [ ] Зарегистрирован аккаунт на GitHub.
- [ ] Установлен VS Code.
- [ ] Установлено расширение Live Server.
- [ ] Создан репозиторий на GitHub (например, `my-first-page`).
- [ ] Создан локальный файл `index.html`.
- [ ] Написан промпт в DeepSeek и получен код.
- [ ] Код скопирован в `index.html`, страница открывается через Live Server.
- [ ] Внесены изменения (имя, хобби, стиль).
- [ ] Файл добавлен в Git (`git add`), закоммичен (`git commit`), запушен (`git push`).
- [ ] Включен GitHub Pages в настройках репозитория (Settings → Pages → Branch: main, /root).
- [ ] Сайт доступен по адресу `https://ваш_логин.github.io/имя_репозитория/`.
