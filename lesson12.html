Как работают онлайн-платежи на статическом сайте?

На статическом сайте (GitHub Pages) у вас нет серверной части, поэтому вы не можете обрабатывать платежи напрямую. Но вы можете использовать платёжные ссылки или виджеты, которые перенаправляют пользователя на защищённую страницу платёжной системы.

Схема работы:

  1. Пользователь нажимает кнопку «Оплатить» на вашем сайте.
  2. Он перенаправляется на платёжную страницу ЮKassa или Stripe.
  3. Там он вводит данные карты и подтверждает платёж.
  4. После успешной оплаты пользователь возвращается на ваш сайт (на страницу успеха).
  5. Вы получаете уведомление о платеже (по email или в личном кабинете).

Вам не нужен сервер, потому что всё взаимодействие происходит на стороне платёжной системы. Вы просто размещаете ссылку.

В этом уроке мы используем платёжные ссылки — это самый простой способ для статического сайта.

Платёжная ссылка и тестовый режим

Что такое платёжная ссылка (Payment Link)?

  • Готовая страница оплаты, созданная в личном кабинете платёжной системы.
  • Вы указываете сумму, описание товара и URL-адрес для возврата после оплаты.
  • Система генерирует уникальную ссылку, которую вы размещаете на сайте.

Что такое тестовый режим (sandbox)?

  • Среда для имитации оплаты без списания реальных денег.
  • Используются тестовые карты (например, 4242 4242 4242 4242 для Stripe).
  • По завершении настройки переключаетесь на боевой режим.

Шаг 1. Регистрация в платёжной системе

Вариант А: ЮKassa (для России)

  1. Перейдите на yookassa.ru и нажмите Зарегистрироваться.
  2. Заполните данные (для тестового режима подойдут любые).
  3. Войдите в личный кабинет → Настройки → Ключи API.
  4. Скопируйте shopId и Secret key (тестовые).

Вариант Б: Stripe (международный)

  1. Перейдите на stripe.com и нажмите Start now.
  2. Зарегистрируйтесь и войдите в дашборд. Включите тестовый режим (правый верхний угол).
  3. В левом меню выберите Payment Links или Products → Add product.

Шаг 2. Создание платёжной ссылки

Для ЮKassa:

  1. Личный кабинет → Приём платежей → Ссылки на оплату.
  2. Нажмите Создать ссылку.
  3. Укажите сумму, валюту (RUB), описание.
  4. В поле URL для возврата укажите адрес страницы успеха на вашем сайте.
  5. Сохраните — вы получите ссылку вида https://pay.yookassa.ru/s/XXXXXXXXXX.

Для Stripe:

  1. Дашборд → Products → Add product (если ещё не создали).
  2. Введите название, цену, выберите One-time (разовая) или Recurring (подписка).
  3. Нажмите Save product, затем Create payment link.
  4. Скопируйте полученную ссылку.

Шаг 3. Добавляем кнопку на сайт

Теперь попросите AI сгенерировать кнопку, которая ведёт на вашу платёжную ссылку. Подставьте в промпт полученную ссылку:

«Добавь на мою страницу красивую кнопку «Оплатить курс — 5000 ₽», которая открывает платёжную ссылку ПЛАТЁЖНАЯ_ССЫЛКА в новой вкладке. Сделай кнопку заметной: зелёная, с закруглениями, тенью и эффектом при наведении. Используй класс btn-pay и покажи CSS для неё.»

Попросите AI разместить кнопку на странице товара, лендинге или на отдельной странице payment.html.

Проверьте: ссылка должна заканчиваться на https://pay.yookassa.ru/s/... или на ссылку Stripe — это и есть ваша платёжная ссылка из шага 2.

Шаг 4. Создаём страницу успеха

Создайте страницу success.html, на которую вернётся пользователь после оплаты. Попросите AI сгенерировать её:

«Создай страницу success.html в моём стиле: заголовок «Оплата прошла успешно!», благодарность, текст "Мы отправим вам доступ к курсу в течение 10 минут", контакт для вопросов @your_support и кнопку «На главную», ведущую на index.html. Добавь адаптивный CSS под мой сайт.»

Не забудьте: укажите адрес этой страницы в настройках платёжной ссылки (поле «URL для возврата»).

Шаг 5. Тестирование

5.1. Проверка в тестовом режиме

  1. Перейдите на сайт и нажмите кнопку «Оплатить».
  2. Вы попадёте на платёжную страницу (в тестовом режиме).
  3. Используйте тестовую карту:
    • Stripe: 4242 4242 4242 4242, любой срок, CVC 123.
    • ЮKassa: тестовые карты из документации (например, 5555 5555 5555 4444).
  4. Завершите оплату и проверьте возврат на страницу успеха.

5.2. Проверка в боевом режиме (если готовы)

  1. Переключите режим на «Боевой» (Live mode).
  2. Создайте новую платёжную ссылку для реальных денег и замените её на сайте.
  3. Проверьте реальный платёж (можно на небольшую сумму, например, 1 рубль).

Шаг 6. Уведомления о платежах

Для статического сайта уведомления о платежах приходят:

  • На email, указанный при регистрации.
  • В личный кабинет платёжной системы.
  • В Telegram — можно через webhook, но для статики сложнее; проще проверять личный кабинет.

Совет: для учебного курса достаточно email-уведомлений. Автоматическую активацию доступа можно настроить позже с использованием серверных решений.

Домашнее задание

  1. Зарегистрируйтесь в ЮKassa или Stripe (бесплатно).
  2. Создайте платёжную ссылку для своего товара/услуги (в тестовом режиме).
  3. Добавьте кнопку с этой ссылкой на ваш сайт.
  4. Создайте страницу успеха и укажите её URL в настройках ссылки.
  5. Проведите тестовую оплату (без реальных денег) и убедитесь, что всё работает.
  6. Закоммитьте и запушьте все изменения.
