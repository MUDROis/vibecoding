# 📝 Готовые промпты для каждого урока

В этом файле собраны проверенные промпты (запросы к нейросетям) для всех занятий курса. Вы можете копировать их и вставлять в DeepSeek, Qwen или ChatGPT.

## Урок 1 — Первая страница

**Промпт 1.1 (базовый):**
> Напиши HTML-код страницы с моим именем (например, "Анна"), моим фото (используй плейсхолдер: https://via.placeholder.com/150), и списком моих увлечений (например: чтение, путешествия, фотография). Используй современные стили: фон светло-серый, заголовок синий, шрифт без засечек, картинка по центру, список аккуратный. Всё на русском языке.

**Промпт 1.2 (для школы):**
> Создай HTML-страницу для школы иностранных языков. На странице должно быть: название школы, краткое описание (2-3 предложения), список преимуществ (например: опытные преподаватели, индивидуальный подход, современные методики), контактная информация (телефон, email). Используй приятную цветовую гамму (белый, синий, акценты оранжевые). Адаптивно, красиво.

**Промпт 2.2 (добавить функции):**

## Урок 3 — Лендинг

**Промпт 3.1 (структура лендинга):**
> Создай HTML-структуру лендинга для школы (например, английского языка). Блоки: хедер с логотипом и меню; первый экран с заголовком и кнопкой; блок о нас с тремя преимуществами; блок программ с тремя карточками; блок отзывов с тремя цитатами; футер с контактами. Сделай адаптивным (Mobile First), используй семантическую разметку. Весь текст на русском.

**Промпт 3.2 (подбор цветов):**
> Предложи цветовую палитру для образовательного сайта. Хочу спокойные, но яркие цвета, вызывающие доверие и вдохновение. Дай коды HEX для основного, вторичного, акцентного цветов, а также для текста и фона.

**Промпт 3.3 (генерация текстов):**
> Напиши текст для блока "О нас" для школы английского языка. Укажи: год основания, количество выпускников, методику (коммуникативный подход), сертификаты. Тон — дружелюбный, профессиональный. 100-150 слов.

## Урок 4 — Firebase

**Промпт 4.1 (отправка данных в Firebase):**
> У меня есть HTML-форма с полями: name (текст), phone (текст), email (текст). Напиши JavaScript-код, который при отправке формы отправляет данные в Firebase Firestore в коллекцию requests. Используй Firebase SDK. Конфигурация: [вставьте ваш объект firebaseConfig]. При успехе выводи сообщение "Спасибо! Заявка отправлена.", при ошибке — "Ошибка, попробуйте позже". Код должен работать в браузере.

**Промпт 4.2 (проверка дублей):**
> Дополни код отправки в Firebase: перед отправкой проверь, есть ли уже запись с таким email в коллекции requests. Если есть, покажи сообщение "Вы уже оставляли заявку". Используй метод getDocs с фильтром where по email.

**Промпт 4.3 (уведомления в Telegram):**
> Напиши функцию на JavaScript, которая после успешной отправки данных в Firebase отправляет сообщение в Telegram бот. Токен бота: токен, chat_id: id. Сообщение должно содержать имя, телефон, email. Используй fetch.

## Урок 5 — Git и бэкап

**Промпт 5.1 (автоматический бэкап через GitHub Actions):**
> Создай GitHub Actions workflow, который каждый день в 3:00 делает коммит и пушит изменения в репозиторий. Используй действия actions/checkout, затем скрипт git add, git commit -m "Автоматический бэкап", git push. Если изменений нет, коммит не создавать.

**Промпт 5.2 (бэкап базы данных Firebase):**
> Напиши скрипт на Node.js, который через Firebase Admin SDK экспортирует коллекцию requests в JSON-файл и сохраняет в папку backups. Для запуска в GitHub Actions.

## Урок 6 — GitHub Actions

**Промпт 6.1 (автоматический деплой):**
> Создай GitHub Actions workflow для автоматического деплоя статического сайта на GitHub Pages при пуше в ветку main. Используй actions/checkout, затем actions/upload-pages-artifact и actions/deploy-pages. Или используй peaceiris/actions-gh-pages.

**Промпт 6.2 (проверка битых ссылок):**
> Добавь в workflow шаг, который проверяет все ссылки на сайте на битые. Используй инструмент linkinator (можно установить через npm). При обнаружении битой ссылки, workflow должен завершиться с ошибкой.

**Промпт 6.3 (уведомление в Telegram):**
> Добавь в workflow отправку сообщения в Telegram об успешном деплое. Используй appleboy/telegram-action. Токен и chat_id хранить в секретах GitHub.
