# ✅ Чек-листы для бонусных уроков (модуль «ПРОФИ»)

Эти чек-листы помогут вам не пропустить ни одного шага бонусных уроков. Отмечайте пункты по мере выполнения.

---

## Урок 10 — PWA

- [ ] Создан `manifest.json` и вставлена ссылка на него в HTML.
- [ ] Созданы иконки (192x192 и 512x512) и добавлены в проект.
- [ ] Создан файл `sw.js`.
- [ ] Service Worker зарегистрирован на странице.
- [ ] В Chrome вкладка Application показывает манифест и SW.
- [ ] Сайт работает офлайн (при отключении интернета).
- [ ] В адресной строке появилась кнопка установки.
- [ ] Приложение успешно установлено на телефон/десктоп.
- [ ] Обновлён кэш и проверено автообновление.
