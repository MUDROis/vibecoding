# ✅ Чек-листы для бонусных уроков (модуль «ПРОФИ»)

Эти чек-листы помогут вам не пропустить ни одного шага бонусных уроков. Отмечайте пункты по мере выполнения.

---

## Урок 10 — PWA

- [ ] Создан `manifest.json` и вставлена ссылка на него в HTML.
- [ ] Созданы иконки (192x192 и 512x512) и добавлены в проект.
- [ ] Создан файл `sw.js`.
- [ ] Service Worker зарегистрирован на странице.
- [ ] В Chrome вкладка Application показывает манифест и SW.
- [ ] Сайт работает офлайн (при отключении интернета).
- [ ] В адресной строке появилась кнопка установки.
- [ ] Приложение успешно установлено на телефон/десктоп.
- [ ] Обновлён кэш и проверено автообновление.

---

## Урок 11 — Telegram-бот для уведомлений о заявках

- [ ] Создан Telegram-бот через BotFather.
- [ ] Получен токен бота и chat_id.
- [ ] Код отправки уведомлений добавлен в обработчик формы.
- [ ] Уведомления приходят при отправке заявки локально.
- [ ] Уведомления приходят на опубликованном сайте.
- [ ] Все изменения запушены на GitHub.

---

## Урок 12 — Приём платежей на сайте без сервера

- [ ] Зарегистрировались в ЮKassa или Stripe.
- [ ] Создали платёжную ссылку (в тестовом режиме).
- [ ] Добавили кнопку «Оплатить» с платёжной ссылкой на сайт.
- [ ] Создали страницу успеха `success.html`.
- [ ] Указали URL страницы успеха в настройках ссылки.
- [ ] Провели тестовую оплату (тестовая карта).
- [ ] Платеж прошёл, возврат на страницу успеха работает.
- [ ] Изменения закоммичены и запушены.

---

## Урок 13 — Docker для изоляции приложений

- [ ] Docker Desktop установлен и работает.
- [ ] Команда `docker --version` показывает версию.
- [ ] Тестовый контейнер `hello-world` запускается.
- [ ] Создана папка с сайтом и файл `Dockerfile`.
- [ ] Создан файл `.dockerignore`.
- [ ] Образ собран командой `docker build -t my-site .`.
- [ ] Контейнер запущен: `docker run -d -p 8080:80 --name my-site-container my-site`.
- [ ] Сайт открывается по `http://localhost:8080`.
- [ ] Контейнер остановлен и удалён (опционально).

---

## Урок 14 — Монетизация проектов

- [ ] Определён продукт и стратегия монетизации.
- [ ] Создана страница продажи с описанием, ценой и кнопкой.
- [ ] Подключена платёжная система (из урока 12).
- [ ] Настроена автоматическая выдача доступа после оплаты.
- [ ] Протестирован процесс (песочница → оплата → доступ).
- [ ] Запущен продукт (страница опубликована).
- [ ] Есть обратная связь от первых пользователей.
